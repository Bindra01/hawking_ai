# hawking_ai

Gamified physics practice app: Next.js 16, Prisma with PostgreSQL, and Supabase auth.

## Getting started

1. `npm install`
2. Copy `.env.example` to `.env` and set the values.
3. `npm run db:push`, then `npm run db:seed`.
4. `npm run dev`, then open http://localhost:3000.

Agent and check commands are in `AGENTS.md`.
