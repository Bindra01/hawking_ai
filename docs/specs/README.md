# Hawking Solve specifications

These are the product specifications for the Solve feature, kept in the repo
so every session can read them. They are the owner's documents, copied
verbatim. The code that implements them lives in `lib/generate-solution.ts`
(prompts and the OpenAI pipeline), `app/api/solve/route.ts` (request
handling, deadlines, error mapping), and the Solve renderers.

Read them in this order:

1. `HAWKING-SOLVE-FEATURE-SPEC.md` — the original build specification:
   inputs, the Short and Long formats, the JSON schema, and the UI.
2. `HAWKING-SHORT-FORMAT-FIX.md` — one Long JSON per problem; the renderer
   derives Short from it.
3. `HAWKING-SHORT-FORMAT-WORKED-DERIVATION.md` — Short is a worked
   derivation (equations only), not a trimmed Long.
4. `HAWKING-STEP-LABELS-FIX.md` — the four step labels are fixed by the app
   and never generated by the model.
5. `HAWKING-SOLUTION-PROMPT-ACCURACY.md` — temperature 0, the ACCURACY
   REQUIREMENTS block with exact physical constants, and the two-call
   pipeline (physics call, then formatting call).

Later specifications override earlier ones where they conflict.
